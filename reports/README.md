# Reportes locales

Este directorio contiene resultados generados por simulaciones, pruebas,
benchmarks, diagnósticos y revisiones visuales. Sus archivos se conservan
localmente y están excluidos de Git, incluidas las subcarpetas.

Solo se versionan este README y la guía histórica de `phase3_pilots/`.
Las reglas, comandos reproducibles y resúmenes de validación se documentan en
`docs/`. Las referencias a archivos de `reports/` en esa documentación describen
evidencias locales; esos archivos pueden no existir en una clonación nueva.

No usar `git add -f` para incluir resultados de una corrida. Los reportes que ya
se publicaron en commits anteriores permanecen en el historial de Git.
